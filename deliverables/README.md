# 零一交付文件

本目录保存零一 AI 日新社的可复用交付文件。官网实际使用的素材由 `src/assets/`、`public/` 和对应数据配置维护；修改本目录不会自动更新官网。

| 目录或文件 | 用途 |
| --- | --- |
| [品牌素材/独立Logo](./品牌素材/独立Logo/) | 透明底黑、白两版 SVG 与 PNG，规格见目录内使用说明 |
| [品牌素材/横版Logo](./品牌素材/横版Logo/) | 图标与完整社名的横版组合、使用说明及配套效果图 |
| [品牌素材/零一Logo-上下留白各20pt.png](./品牌素材/零一Logo-上下留白各20pt.png) | 已导出的留白版本 |
| [旗帜/泉州海洋分社旗帜.pdf](./旗帜/泉州海洋分社旗帜.pdf) | 泉州海洋分社旗帜 PDF |
| [历史方案/字标-第一版](./历史方案/字标-第一版/) | 第一版十款字标、HTML 浏览入口、总览和打包文件 |
| [历史方案/字标-第二版](./历史方案/字标-第二版/) | 第二版十款字标、HTML 浏览入口、总览和打包文件 |

历史字标方案保留原始素材和压缩包的文件名，供回看与复用，不代表官网当前采用的字形。Logo 的黑白效果图、字标总览和比较图是交付包的一部分，应随包保留。

`验收截图/` 仅在本机保存历史上线记录，已由 Git 忽略；截图反映拍摄时的页面，不作为当前线上版本的依据。过程预览、调试日志和渲染中间文件应放入 `tmp/` 或系统临时目录，任务结束后清理。

原始图片备份位于项目本机的 `output/image-originals/`，分社旗帜的其他印刷 PDF 位于 `output/pdf/`；它们不纳入 Git，也不应作为临时文件删除。
