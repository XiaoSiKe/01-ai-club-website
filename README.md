零一 AI 日新社（01AIClub）是一个以公益教学为核心的 AI 兴趣社团、知识库与交流社区，面向 AI 初学者、转专业探索者和愿意参与开源实践的同学。

- 所属标识：AI CLUB · 福州大学
- 成立时间：2026 年 9 月 1 日
- 发起人：零一扬

> 从零到一，让技术进步成为每个人的机会
>
> From Zero to One, Turning Technology into Opportunity for Everyone

## 本地开发

当前改动先使用本地 Docker 预览；未经明确要求，不推送或部署到线上。

```bash
docker compose up -d
```

浏览器打开 `http://localhost:5174/`。源代码修改会自动刷新；容器依赖保存在独立的 Docker volume 中。

停止预览：

```bash
docker compose down
```

也可以使用本机 Node.js 开发：

要求：Node.js `^20.19.0` 或 `>=22.12.0`，并使用随 Node.js 提供的新版 npm。

```bash
npm ci
npm run dev
```

Vite 会输出本地访问地址。当前开发环境通常使用 `http://localhost:5174/`，实际端口以终端输出为准。

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`。提交代码前至少运行一次 `npm run build`。

GitHub 的 `Website checks` 会在每个 PR 及 main 更新时，使用 `.nvmrc` 指定的 Node.js 干净安装依赖并执行完整构建，包含自动发布入口回归、地图完整性、相机切换、分区入场和静态文件校验。PR 只执行检查；main 的检查通过后，经 HTTPS 自动触发现有云效流水线，并等待官网版本号与本次提交一致后才标记成功。触发地址保存在 GitHub Actions Secret 中，工作流的仓库权限仍仅为源码读取。浏览器交互和手机布局仍须按下文手动验证。

## 接入真实内容

- **零一商业**：编辑 `src/data/business.js` 的 `src`、`alt`、`title`、`subtitle`、`captionCredit`、`href`，必要时设置 `imageScale` 调整 Logo 显示大小；`members` 配置各项目成员的 `name`、`src`，`membersExample` 标识是否为演示数据。项目成员名单集中在 `src/data/business-members.js`，同名成员共享 `src/data/member-portraits.js` 中的原色头像，图片位于对应的 `public/images/business-members-*` 文件夹。当前顺序为零一快剪 → 零一拓饮 → 零一智械 → 零一课表；原图位于 `public/images/business-*.png`。

以下项目、活动与手记配置对应保留的展示组件，目前未挂载到首页；修改配置不会自动恢复被移除的模块。加入区的公众号二维码仍通过 `wechatChannel.qr` 配置。

- **项目**：编辑 `src/data/projects.js` 中的名称、描述、分类和标签，将 `url` 填为真实项目网页；留空会进入本站项目页。可添加 `image: '/images/项目封面.webp'` 展示自己的封面，或使用 `artwork: 'knowledge' | 'study' | 'studio' | 'tools'` 沿用内置视觉。仅当网页和介绍已核实时，将 `demo` 改为 `false`。本地四个示例页仍是体验原型，不能通过去掉标签变成已上线产品。
- **活动**：编辑 `src/data/community.js` 的 `communityMoments`，替换 `image`、`imageAlt`、标题与描述。图片放入 `public/images/`，配置使用 `/images/文件名`；确认照片使用授权及活动事实后才将 `isExample` 改为 `false`。现有三张照片为 AI 生成示意，提示词与来源见 `public/images/README.md`。
- **公众号**：在同文件的 `wechatChannel` 填写已核实的 `name`、公众号 ID `account`、网页 `url` 和二维码图片路径 `qr`。未提供入口时，页面说明待补充并引导至加入区域；不会生成假二维码。
- **手记**：编辑 `communityPublications` 的标题、摘要、分类与正文。填写 `url` 后打开真实发布页；留空则打开站内全文。只有确认文章真实且可发布后，才移除其 `isExample` 标记。

替换后运行 `npm run build`，并在桌面和手机宽度下检查链接、图片、导航、弹窗关闭与焦点返回；同时检查系统减少动态效果模式。构建通过不能替代这些实际交互检查。

## 设计与交互原则
