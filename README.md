# 零一 AI 日新社官网

零一 AI 日新社（01 AI CLUB）是一个面向 AI 探索者、向全社会开放的创新共创社区。我们探索能在真实世界中落地的“大学｜学习新范式”，在交流与实践中完成从零到一。

> 从零到一，让技术进步成为每个人的机会！

[访问官网](https://club.01aiedu.com/) · [反馈问题](https://github.com/XiaoSiKe/01-ai-club-website/issues) · [参与贡献](./CONTRIBUTING.md)

## 本地开发

React + Vite。Node.js 版本见 [`.nvmrc`](./.nvmrc)。

```bash
npm ci
npm run dev
```

打开终端显示的地址。

## 检查与构建

```bash
npm run test:runtime
npm run build
npm run preview
```
