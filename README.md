# 零一 AI 日新社官网

零一 AI 日新社（01AIClub）是一个以公益教学为核心的 AI 兴趣社团、知识库与交流社区，面向 AI 初学者、转专业探索者和愿意参与开源实践的同学。

- 正式域名：<https://club.01aiedu.com>
- 所属标识：AI CLUB · 福州大学
- 成立时间：2026 年 9 月 1 日
- 发起人：零一扬

> 从零到一，让技术进步成为每个人的机会
>
> From Zero to One, Turning Technology into Opportunity for Everyone

分社详情不重复挂载整张面板或重播透明入场；学校照片已替换为官方透明校徽，来源见 `public/images/branches/crest-sources.json`。选中标记使用静态光圈，标签换边、上下排布和可见性采用稳定区，避免高倍缩放临界点闪动；投影原点设在大学城附近，减少大坐标变换造成的细线抖动。

地图使用 `atlasPainter.js` 的双缓冲 Canvas 绘制：地理路径只编译一次为 Path2D，按当前视口裁切和当前缩放比例选择层级，整帧完成后再统一复制到可见画布。切换不再隐藏、插入或重排 SVG 图层；HTML 标记、面包屑、学校列表与键盘操作保持可访问。颜色由 `atlasPalette.js` 同时提供给画布和界面，校徽保留原色。

首次滚入时，35 个地图区域按地理顺序逐块淡入、上浮 18px：相邻区域错开 24ms，各自持续 640ms，整段约 1.46 秒。初始保留淡轮廓，卡片、标题和信息栏配合轻微上浮，交互时立即完成入场，只播放一次。进度通过 ref 驱动画布整帧重绘，复用已编译路径，不逐帧更新 React 或插拔地理节点；减少动态时直接显示完整地图。`scripts/verify-atlas-reveal.mjs` 验证各区透明度与位移单向收敛、错落顺序和最终位置，已纳入构建。右栏为 380px（中屏 340px），桌面地图区域固定高度 776px，学校增多时仅侧栏列表内部滚动，切换学校时保持稳定；手机地图固定高 400px、信息栏固定高 600px。搜索保持无边框输入样式，以底线提示焦点。

## 本地开发

当前改动先使用本地 Docker 预览；未经明确要求，不推送或部署到线上。

```bash
docker compose up -d
```

浏览器打开 `http://localhost:5174/`。源代码修改会自动刷新；容器依赖保存在独立的 Docker volume 中。

停止预览：

```bash
docker compose down
```

也可以使用本机 Node.js 开发：

要求：Node.js `^20.19.0` 或 `>=22.12.0`，并使用随 Node.js 提供的新版 npm。

```bash
npm ci
npm run dev
```

Vite 会输出本地访问地址。当前开发环境通常使用 `http://localhost:5174/`，实际端口以终端输出为准。

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`。提交代码前至少运行一次 `npm run build`。

GitHub 的 `Website checks` 会在每个 PR 及 main 更新时，使用 `.nvmrc` 指定的 Node.js 干净安装依赖并执行完整构建，包含地图完整性、相机切换、分区入场和静态文件校验。此检查仅有源码读取权限，不执行部署；main 的发布仍由现有云效流水线负责。浏览器交互和手机布局仍须按下文手动验证。

## 接入真实内容

- **零一商业**：编辑 `src/data/business.js` 的 `src`、`alt`、`title`、`subtitle`、`captionCredit`、`href`，必要时设置 `imageScale` 调整 Logo 显示大小；`members` 配置各项目成员的 `name`、`src`，`membersExample` 标识是否为演示数据。项目成员名单集中在 `src/data/business-members.js`，同名成员共享 `src/data/member-portraits.js` 中的原色头像，图片位于对应的 `public/images/business-members-*` 文件夹。当前顺序为零一快剪 → 零一拓饮 → 零一智械 → 零一课表；原图位于 `public/images/business-*.png`。

以下项目、活动与手记配置对应保留的展示组件，目前未挂载到首页；修改配置不会自动恢复被移除的模块。加入区的公众号二维码仍通过 `wechatChannel.qr` 配置。

- **项目**：编辑 `src/data/projects.js` 中的名称、描述、分类和标签，将 `url` 填为真实项目网页；留空会进入本站项目页。可添加 `image: '/images/项目封面.webp'` 展示自己的封面，或使用 `artwork: 'knowledge' | 'study' | 'studio' | 'tools'` 沿用内置视觉。仅当网页和介绍已核实时，将 `demo` 改为 `false`。本地四个示例页仍是体验原型，不能通过去掉标签变成已上线产品。
- **活动**：编辑 `src/data/community.js` 的 `communityMoments`，替换 `image`、`imageAlt`、标题与描述。图片放入 `public/images/`，配置使用 `/images/文件名`；确认照片使用授权及活动事实后才将 `isExample` 改为 `false`。现有三张照片为 AI 生成示意，提示词与来源见 `public/images/README.md`。
- **公众号**：在同文件的 `wechatChannel` 填写已核实的 `name`、公众号 ID `account`、网页 `url` 和二维码图片路径 `qr`。未提供入口时，页面说明待补充并引导至加入区域；不会生成假二维码。
- **手记**：编辑 `communityPublications` 的标题、摘要、分类与正文。填写 `url` 后打开真实发布页；留空则打开站内全文。只有确认文章真实且可发布后，才移除其 `isExample` 标记。

替换后运行 `npm run build`，并在桌面和手机宽度下检查链接、图片、导航、弹窗关闭与焦点返回；同时检查系统减少动态效果模式。构建通过不能替代这些实际交互检查。

## 设计与交互原则

- 保留黑白透视扫描空间、回声标题和透明分层菜单三个品牌特征。
- 不虚构社团规模、合作企业、课程成果或成员数据。
- 所有站内导航使用平滑滚动，并尊重系统的“减少动态效果”设置。
- 核心内容不能依赖动画才能阅读；卡片悬停保留边缘高光，正文颜色与透明度保持稳定。
- “社团导航”左侧支持深浅色切换，并在本机记住选择；首页及项目页共用主题。主题状态在 `src/Theme.jsx` 维护，配色适配在 `src/theme.css`。
- 桌面端和移动端都必须避免横向溢出。

“零一科研与竞赛”位于商业与高校分社之间。DriftWall 左侧为竖版证书，中间为四张 3:2 横版比赛照片，右侧为横版证书；手机缩为三列并保留同样分组。证书保持原始长宽比，采用 contain 显示完整内容。数据集中在 `src/data/competition.js`。列高按真实卡片高度累加，重复副本覆盖视口和上下预留空间，实现连续循环；仅暂停悬停列。关闭大图时清除键盘、悬停等暂停标记；唤醒时按当前视口位置判断可见性，滚动、尺寸变化和观察器回调统一复核实际位置，避免片段定位或关闭预览后被滞后的离屏状态卡住；循环唤醒的首帧即使速度为零，只要目标速度非零也继续请求下一帧，避免弹窗停留后永久停帧。`scripts/probe-drift-wall-resume.js` 覆盖完全停帧后通过按钮、Esc 和背景退出的恢复场景，可在本地页面通过 CDP 运行。默认亮度 0.72，悬停恢复为 1。根节点统一处理指针点击，按按下时的稳定卡片锁定目标，并阻止鼠标焦点重排。原生 dialog 先显示预览图，再渐入高清图；右下角退出按钮共用首页“关于我们”的 SpecularButton 参数，以 CSS 绘制高光。电脑端图片说明字号与商业区主张一致，为 clamp(19px, 2vw, 24px)，760px 及以下保持 14px。保留 Esc、背景退出及焦点恢复，减少动态时按相同分组静态显示全部十张素材。

照片墙首次滚入时按画面上、中、下三组依次展开，各组滚至视口 88% 位置才触发，组内照片错开 50ms，淡入并轻微上浮。展开期间暂停漂移，全部显示后恢复循环；回滚不重播，键盘或点击操作可立即完成入场。`scripts/probe-drift-wall-reveal.js` 在桌面及手机宽度验证逐组时机、透明度单向变化、循环恢复与无横向溢出。

首屏组件位于 `src/components/ui/perspective-tunnel-hero.jsx`，直接采用用户新参考中的 Framer Motion、useMotionValue、useSpring 与 useTransform。进度初始为 0，没有自动播放；输入滚轮后按 `deltaY * 0.0008` 推进，进度弹簧为 stiffness 80、damping 30、restDelta 0.0001，指针弹簧为 stiffness 60、damping 25、mass 0.5。照片的黄金角、交错区间、Z 轴、淡入淡出、透视与宽度均沿用参考代码；移除此前 GSAP 近似、中央蒙版和图片调暗。初次进入十二张照片都隐藏，滚动后出现；滚动到端点释放页面自然滚动，触屏按同样进度累加。社团名称、口号和三个按钮仍在同一首屏内，照片层不拦截按钮点击。十二张活动照片的宽高记录在 `src/data/activity-photos.js`，横版、竖版、方形均按原始比例完整展示，取代参考中固定的 4:5 画幅。减少动态时取消飞行动作，只保留滚动显隐。

地图可见性通过实时视口边界判断，并以滚动／尺寸变化补充 IntersectionObserver。离屏和后台只暂停、保留相机状态，回到屏幕后从原位置继续。绘制表面固定为视口大小，各区域在后台画布中合成，主画布不在两层之间清空。`scripts/probe-atlas-visibility.js` 验证离屏暂停与恢复；`scripts/probe-atlas-paint.js` 记录帧间隔、长帧和实际变化的位置数量，防止跳到终点被误判为动画通过。

切换时不在 React 布局效果中读取地图位置；输入捕获阶段仅在可见性缓存为 false 时补查。首屏 EchoText 离屏或页面进入后台后暂停，静止后停帧，鼠标输入再唤醒，避免回声标题与地图争用每帧的绘制时间。详情校徽在空闲期缓存完整的小尺寸像素，切换只更新小画布，保留原色、透明边缘和可访问名称。
